# Shapeshop

Simple, powerful 3D modelling for 3D printing — drag shapes, cut holes, round edges, scan objects from photos, and export STL, 3MF or OBJ.

## Download

Get the latest version from **[Releases](../../releases/latest)**.

**Windows (64-bit):** download `Shapeshop-Setup-….exe` and run it. The installer isn't signed yet, so Windows may show "Windows protected your PC": click **More info → Run anyway**.

**Mac (Apple silicon or Intel):** download `Shapeshop-…-mac.dmg`, open it and drag Shapeshop to Applications. It isn't signed by Apple yet, so the first time macOS won't open it: go to **System Settings → Privacy & Security** and click **Open Anyway** (once per version).

**Linux (64-bit):** download the `.AppImage`, make it executable (right-click → Properties → Allow executing as program, or `chmod +x Shapeshop-*.AppImage`) and open it.

Updating keeps your projects and settings.

Photo scanning (desktop app) downloads its add-on — COLMAP and the parts it needs — from their official sources the first time you use it. It works on 64-bit Linux and Windows PCs and on Macs with Apple silicon (macOS 14 or newer); an NVIDIA graphics card (Linux or Windows) gives the detailed result.
