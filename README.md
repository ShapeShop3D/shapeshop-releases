# Shapeshop

Simple, powerful 3D modelling for 3D printing — drag shapes, cut holes, round edges, scan objects from photos, and export STL, 3MF or OBJ.

## Download

Get the latest version from **[Releases](../../releases/latest)**.

**Linux:** download the `.AppImage`, make it executable (right-click → Properties → Allow executing as program, or `chmod +x Shapeshop-*.AppImage`) and open it. Updating keeps your projects and settings.

Photo scanning (desktop app) downloads its add-on — COLMAP and the parts it needs — from their official sources the first time you use it. It works on any 64-bit Linux PC; an NVIDIA graphics card gives the detailed result.
